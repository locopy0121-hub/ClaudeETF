# ClaudeETF — 台美股資產管理 App（開發版）

一個 Android App 同時管理台股與美股：總資產以台幣看全貌，個股與交易保留原幣細節。
全程不用電腦，由 GitHub Actions 雲端建置 APK。

## 下載安裝

1. 打開本專案的 **Releases** 頁面（手機瀏覽器即可）
2. 點最新的 `ClaudeETF-v0.1.N-dev.apk` 下載並安裝
3. 簽章固定，新版本可直接覆蓋安裝，資料保留

每次推送到 `main` 都會自動建置，版本號 `0.1.N-dev` 的 N 為建置編號，每次遞增。
也可以在 **Actions › Build APK › Run workflow** 手動觸發。

## 第一階段功能（目前版本）

| 分頁 | 畫面 | 內容 |
|---|---|---|
| 總覽 | 總覽 | 總資產（TWD）、今日／未實現損益、資產配置、美股時段、指數 |
| 總覽 | 提醒中心 | 價格、漲跌幅、財報、除息、開盤提醒規則 |
| 行情 | 自選行情 | 台美股混合清單、全部／台股／美股／ETF 篩選、搜尋 |
| 行情 | 個股詳情 | 報價、台幣換算、美股時段、基本面、我的持股損益 |
| 持股 | 持股 | 市值、成本、已實現／未實現、台幣／原幣切換 |
| 持股 | 新增交易 | 買進、賣出、股息、拆股；手續費與證交稅自動計算；零股 |
| 持股 | 股息與稅務 | 年度股息、美股 30% 預扣、每月股息、即將除息 |
| 持股 | 績效分析 | 對比 0050／SPY、美股「股價／匯兌」損益拆解、配置 |
| 市場 | 美股市場 | 交易時段（台灣時間、自動夏冬令）、指數、板塊熱力圖、排行 |
| 市場 | 財經行事曆 | 經濟數據、財報、除息、休市 |
| 我的 | 設定 | 漲跌配色（台式／美式）、匯率、手續費 |

持股、交易、提醒與設定存在手機本機。

## 第二階段：即時行情（已完成）

| 市場 | 來源 | 說明 |
|---|---|---|
| 台股（盤中） | 富果 Fugle MarketData API | 週一至五 08:30–13:35，需在「我的 › 行情資料來源」填入自己的富果 API 金鑰 |
| 台股（盤後／備援） | 證交所 OpenAPI、櫃買中心 OpenAPI | 免金鑰；盤後、未填金鑰或富果失敗時自動改用 |
| 美股、指數、債息、美元指數 | Yahoo Finance | 免金鑰；含當日走勢。Finnhub 金鑰為選填備援 |
| 匯率 | 台灣銀行牌告 | 美元即期買賣中價 |

- 金鑰輸入後自動儲存在手機，可「測試連線」
- App 在前景時自動更新：交易時段每分鐘，其餘每 15 分鐘；也可按更新鈕
- 每檔報價顯示資料來源與更新時間
- 自選清單可搜尋代號加入、在個股頁移出

## 配息稅務（v0.1.5 起）

每檔證券自動判斷稅務類型，可在個股頁「股息」分頁變更，並依投信公告調整「應稅比例」（股利所得占配息比例）：

| 類型 | 預設應稅比例 | 所得稅 | 二代健保 2.11% |
|---|---|---|---|
| 台股一般股票 | 100% | 併入綜所稅 | 單次股利所得 ≥ 2 萬才扣 |
| 國內股票型 ETF | 100%（依公告調整） | 僅股利所得部分 | 僅股利所得部分，≥ 2 萬才扣 |
| 權利金收益型 ETF（如 00406A） | 0% | 停徵 | 不扣 |
| 債券型 ETF（代號 B 結尾） | 0% | 海外所得，最低稅負制 | 不扣 |
| 海外股票型 ETF | 0% | 海外所得，最低稅負制 | 不扣 |
| 美股 | — | 預扣 30% | 不扣 |

記錄股息時依上述規則自動計算扣除與實收金額。

## 市場、行事曆與提醒（v0.1.7 起）

- **市場頁**：美股 11 類股 ETF 熱力圖、Yahoo 漲幅／跌幅／成交量排行；台股證交所類股指數漲跌、收盤漲跌幅與成交量排行（排除成交 < 500 張的冷門股）。點排行可直接開個股頁。
- **財經行事曆**：自選與持股未來 120 天的財報日、除息日、股息發放日；美股休市日；FOMC 利率決議（換算台灣時間）。
- **提醒中心**：可自訂「價格高於／低於、單日漲幅／跌幅、財報前 N 天、除息前 N 天、美股開盤」。App 開著時每次更新都檢查，關閉後由 WorkManager 約每 15 分鐘在背景檢查並推播通知（Android 13 以上需允許通知）。

## 交易紀錄與帳本（v0.1.8 起）

- 持股、現金、已實現損益與股息改由「交易紀錄」重新計算；交易可編輯、刪除，改完自動重算
- 交易紀錄頁：依月份分組、搜尋、類型篩選；賣出顯示已實現損益，股息顯示實收
- 舊版持股自動轉成「期初持股」；「我的 › 帳本」可調整現金餘額、清除示意資料
- 每天記錄總資產，首頁走勢顯示實際淨值變化

## 備份、匯入與真實績效（v0.1.9 起）

- **完整備份／還原**：交易、帳本、自選、提醒、稅務設定與淨值紀錄匯出成一個 JSON 檔；存檔時選 Google 雲端硬碟即為雲端備份（API 金鑰不匯出）
- **交易 CSV 匯入／匯出**：支援常見券商對帳單欄位（中英文）、民國年日期、Big5 編碼；匯入前預覽，全部檢查通過才寫入
- **股息頁**：每月股息、股息紀錄依交易計算；持股即將除息取自財經行事曆
- **績效分析**：以目前持股回測一年對比 0050／SPY（1 月／3 月／6 月／1 年）、最大回撤、年化波動、夏普值；XIRR 依實際現金流計算

## 外觀、小工具與多帳戶（v0.1.10 起）

- **主題**：跟隨系統、深色、淺色；字級小／標準／大／特大
- **桌面小工具**：總資產、今日損益與更新時間，行情更新與背景檢查時自動刷新，點擊開啟 App
- **多帳戶**：可新增多個台股／美股帳戶，設定手續費折扣（例：2.8 折）、費率與最低收費；記帳時選帳戶自動計算手續費；持股頁可依帳戶篩選
