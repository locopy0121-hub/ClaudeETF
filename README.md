# ClaudeETF — 台美股資產管理 App（開發版）

一個 Android App 同時管理台股與美股：總資產以台幣看全貌，個股與交易保留原幣細節。
全程不用電腦，由 GitHub Actions 雲端建置 APK。

## 下載安裝

1. 打開本專案的 **Releases** 頁面（手機瀏覽器即可）
2. 點最新的 `ClaudeETF-v0.1.N-dev.apk` 下載並安裝
3. 簽章固定，新版本可直接覆蓋安裝，資料保留

每次推送到 `main` 都會自動建置，版本號 `0.1.N-dev` 的 N 為建置編號，每次遞增。
也可以在 **Actions › Build APK › Run workflow** 手動觸發。

## 第一階段功能（目前版本）

| 分頁 | 畫面 | 內容 |
|---|---|---|
| 總覽 | 總覽 | 總資產（TWD）、今日／未實現損益、資產配置、美股時段、指數 |
| 總覽 | 提醒中心 | 價格、漲跌幅、財報、除息、開盤提醒規則 |
| 行情 | 自選行情 | 台美股混合清單、全部／台股／美股／ETF 篩選、搜尋 |
| 行情 | 個股詳情 | 報價、台幣換算、美股時段、基本面、我的持股損益 |
| 持股 | 持股 | 市值、成本、已實現／未實現、台幣／原幣切換 |
| 持股 | 新增交易 | 買進、賣出、股息、拆股；手續費與證交稅自動計算；零股 |
| 持股 | 股息與稅務 | 年度股息、美股 30% 預扣、每月股息、即將除息 |
| 持股 | 績效分析 | 對比 0050／SPY、美股「股價／匯兌」損益拆解、配置 |
| 市場 | 美股市場 | 交易時段（台灣時間、自動夏冬令）、指數、板塊熱力圖、排行 |
| 市場 | 財經行事曆 | 經濟數據、財報、除息、休市 |
| 我的 | 設定 | 漲跌配色（台式／美式）、匯率、手續費 |

持股、交易、提醒與設定存在手機本機。

## 第二階段：即時行情（已完成）

| 市場 | 來源 | 說明 |
|---|---|---|
| 台股（盤中） | 富果 Fugle MarketData API | 週一至五 08:30–13:35，需在「我的 › 行情資料來源」填入自己的富果 API 金鑰 |
| 台股（盤後／備援） | 證交所 OpenAPI、櫃買中心 OpenAPI | 免金鑰；盤後、未填金鑰或富果失敗時自動改用 |
| 美股、指數、債息、美元指數 | Yahoo Finance | 免金鑰；含當日走勢。Finnhub 金鑰為選填備援 |
| 匯率 | 台灣銀行牌告 | 美元即期買賣中價 |

- 金鑰輸入後自動儲存在手機，可「測試連線」
- App 在前景時自動更新：交易時段每分鐘，其餘每 15 分鐘；也可按更新鈕
- 每檔報價顯示資料來源與更新時間
- 自選清單可搜尋代號加入、在個股頁移出
